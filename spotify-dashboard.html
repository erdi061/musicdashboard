◈ SETUP — ONE-TIME

This runs entirely in your browser — no server, no database. Your Spotify data never touches anyone but you and Spotify. Follow these four steps once.

  • 1Go to the Spotify Developer Dashboard and log in with your normal Spotify account.
  • 2Click Create app. Give it any name/description. For Redirect URI, paste the exact URL you're viewing this page at right now (shown below) — it must match exactly, including http/https.
  • 3In the app's settings, tick the Web API checkbox, save, then copy the Client ID shown on the app's dashboard page.
  • 4Paste that Client ID below and hit connect. You'll be sent to Spotify to approve access, then dropped back here.
